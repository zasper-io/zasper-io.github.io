Agents

Your agent works in your notebook. You stay in charge.

Bring Claude Code, Gemini CLI, Codex or any agent that speaks ACP. It works in your live kernel, and you can review and undo every change it makes.

  1. 01 · Bring

    Use the agent you already pay for

    It signs in with your own account. Zasper never sees a key or your conversation.

  2. 02 · Work

    Live in your kernel

    It reads cells and outputs, runs code and inspects your data. It can even see your plots.

  3. 03 · Ask

    Nothing happens unasked

    It asks before it edits a file or runs a command. Every cell it runs carries its name.

  4. 04 · Review

    Undo anything

    See each change as a diff. Keep it, or roll back a cell, a file or the whole turn.

Benchmarks

The more you run, the bigger the lead.

We ran Zasper and Jupyter Server against the same load on an Apple M4: 10 requests a second to every kernel, from 2 kernels to 100. Zasper used less memory and less CPU at every step. At 100 kernels, Jupyter Server held 1.9 GB and had dropped every connection. Zasper held 49 MB and answered every request.

FAQ

Questions, answered.

Is Zasper a drop-in replacement for JupyterLab?

For your notebooks and kernels, yes: same files, same kernelspecs, same protocol. It is its own app, though, not a copy of JupyterLab's interface or extension system.

How is Zasper different from a hosted notebook like Hex?

Hex runs your code in its cloud and keeps projects in its own format. Zasper runs on your machine or server, keeps plain .ipynb files, and uses your own agent subscription. Hex suits teams publishing dashboards; Zasper is for the people writing the notebooks. Zasper and Hex, side by side

Do my JupyterLab extensions work?

No. Zasper has its own extension model, so JupyterLab extensions will not load. If one is essential to you, that is a good reason to stay.

Does it work on Windows?

Yes, there is a Windows build. The built-in terminal needs WSL, so we recommend running Zasper under WSL.

Is it really free?

Yes. Under the AGPL-3.0 you can install it, run it, host it and change it. The commercial license is only for building it into a proprietary product.

What happens to my conda and uv environments?

Any environment registered as a Jupyter kernel shows up in the launcher. Zasper also finds the active environment, your base conda install, or a trusted project's .venv, as long as it has ipykernel.

Which coding agents work, and what do they cost?

Claude Code, Gemini CLI, Codex and any agent that speaks ACP. Claude Code is the one tested most. Each runs on your own subscription, so Zasper adds no cost and never holds a key. Agents outside Zasper can connect through its MCP server.

Does my code leave my machine?

No. Zasper runs on your machine, and your files stay there. A coding agent you start talks to its own provider, as it would in a terminal. Zasper sends anonymous usage data with no file names, paths, contents or IP address; ZASPER_TELEMETRY=0 turns it off, and PRIVACY.md lists everything. It also checks zasper.io for updates once a day, and loads widget libraries from jsDelivr unless you turn that off in Settings.
