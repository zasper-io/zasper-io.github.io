To upgrade a binary, replace the zasper you have with the new one; zasper --version says which you have, and a Zasper already running keeps the old one until you restart it. Before moving to a new major version, read its upgrading notes in Installation.

To check a download, fetch zasper_{{ release.version }}_checksums.txt and run sha256sum -c zasper_{{ release.version }}_checksums.txt --ignore-missing beside it. Older versions are on GitHub Releases.
