{% comment %} Per-page metadata. Everything here used to be hardcoded to the homepage: og:url pointed at https://zasper.io/ from every page, so a shared doc or blog post previewed as the front page, and `description` was present but empty. The values are computed once here and reused by head.html for the , so a page's name is written in one place rather than two. These four used to be literals here, because the repository had no _config.yml. It has one now, so they are read from it: the site's name, its description and its URL are written in one place, and the feed and the sitemap read the same values. {% endcomment %} {%- assign
