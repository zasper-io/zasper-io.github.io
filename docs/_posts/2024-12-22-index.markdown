Zasper is an open-source, high-performance IDE for working with Jupyter notebooks. It's built from
scratch to be:

* Fast to start and fast to run
* Highly concurrent, with a small resource footprint
* Resilient under heavy load

It is cross-platform:

* Fully supported: macOS and Linux
* Limited support: Windows — for the best experience, use via WSL

## Benchmarks

How is Zasper better than JupyterLab?

<img src="https://raw.githubusercontent.com/zasper-io/zasper-benchmark/main/assets/summary_resources.png" alt="Benchmark summary" width="600" />

* Up to 5X less CPU usage
* Up to 40X less RAM usage
* Higher throughput
* Lower latency
* Highly resilient under very high loads

The full benchmark report, methodology and raw results are in the
[zasper-benchmark repository](https://github.com/zasper-io/zasper-benchmark?tab=readme-ov-file#benchmarking-zasper-vs-jupyterlab).
